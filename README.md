# biz.dfch.SpecVwr
Opencode plugin that shows biz.dfch.SpecMgr artifacts

## Project

SpecVwr (Spec Viewer) is an OpenCode plugin that shows specmgr artifacts (GOL, REQ, UC, ADR, DEC, RSK, TSK …) in a spreadsheet-like table. A cell is clickable when an artifact refers to another artifact and opens the connected artifact. The first version is read-only. The project is the main example for the Informatikerin EFZ validation procedure (application development). Requirements and decisions are managed with specmgr (`.mcp.json`). The use of AI tools is logged in a local specmgr document, "AI Usage in the SpecVwr Project", which is not part of the repository.
